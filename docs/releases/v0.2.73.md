### Validation

Local validation passed all **89 test scripts**, reporting **1,250 cases including 3 environment-dependent skips**, with **87% branch-aware Python coverage across `rig_cli`**. Seven native ROS probe scenarios passed in an isolated Linux ARM64 container using Lyrical/Fast DDS: a healthy graph, four clock failure modes, a wrong message type and incompatible QoS. These results exercise real ROS endpoints but do not validate Isaac or the walkthrough's Jazzy/Zenoh combination. Hosted release CI results are not claimed here.

### Experimental scope and follow-up

Isaac attachment does not install or launch Isaac, create/load/reset scenes, configure bridge topics, validate sensor payloads or physics, or establish per-frame TF authority. A compatible prepared simulator, transport and service images are required. Live GPU/Isaac and disconnected scene acceptance remain pending.

Collection-profile and fresh real-run acceptance are deferred follow-up checks for this release. Successful startup and recipe compatibility do not guarantee that every deployment retained all inputs needed for future replay or simulation work.
