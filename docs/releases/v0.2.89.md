## Topic exclusions during bag export

Version-2 recipes can use `replay.export.bags.exclude` to remove exact, absolute recorded
ROS topic names while building a bag proxy.

```yaml
replay:
  inputs:
    bags: {profile: sensor-conservative}
  export:
    bags:
      exclude:
        - /diagnostics/bad_stamp
```

A proxy profile is required to create the filtered bag. `use: original` cannot apply these
exclusions. Export and prepare with the same recipe.

```sh
rig run export RUN --recipe replay/analysis.yaml
rig replay prepare RUN --recipe replay/analysis.yaml
```

Excluded topics are skipped before message decoding, sensor timestamp checks and
deduplication. This lets a sensor-time export omit a topic with bad timestamps while
preserving timestamp and clock-skew checks for every remaining topic. `playback.exclude`
only filters replay publications.

Original bags and camera recordings remain unchanged. Reports count excluded messages.
Changing the exclusion set selects a different proxy. An empty or omitted list preserves
existing unfiltered behavior and IDs.

## Upgrade

Use Rig v0.2.89 with the **rig-infra v1.22.0 bag-player launcher bundle**. Re-bake and
redeploy to update both bundled components. Updating another Rig installation does not
update an existing artifact.

Check the artifact with `./rig --version`, or an installed CLI with `rig --version`.
The expected output is `rig 0.2.89`.
