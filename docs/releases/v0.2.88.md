## Shared run UUIDs

`rig fleet up --run survey` gives participating vehicles a common `run_uuid`. Each vehicle
writes that UUID to its own run manifest. A retry reuses the UUID of the open run, and a
late-joining vehicle can obtain it from a reachable peer. Once the runs are sealed, reusing
the label starts a new acquisition. If open runs with the requested label disagree on the
UUID, Rig reports the conflict.

The rig-infra v1.21.0 recorder reads the UUID when recording starts. On supported Lyrical
Zenoh MCAP recordings, a conservative bag export can then recognize the same publication
recorded on different hosts in the same ROS domain. The original bags keep every recorded
message. Copies with missing or conflicting publication evidence are retained by the
conservative publication check.

In a two-host test, each logger recorded the same 24 publications from two publisher
instances. All messages had identical payloads. After a bag export, a conservative merge
retained 24 of the 48 input records and identified the other 24 by publication identity.

Use `rig status --format json` to inspect `open_run.run_uuid`. To join a known acquisition
outside a fleet command, use `rig up --run survey --run-uuid <uuid>`. Older run manifests
remain readable. An open run created without a UUID keeps its original recording scope.

## Observer in the example vehicle

The repository's Orin configuration now starts the Zenoh router, bag recorder and observer
in that order. The observer writes graph epochs, host inventory, system samples and settings
to the run directory and publishes `/diagnostics`. Its configuration is in
`config/infra/observer.yaml`. The bag logger's legacy `graph` block has been removed from
the example. Existing deployments can migrate their config independently.

## Upgrade

Use Rig v0.2.88 on the fleet controller and participating deployments. If a vehicle runs a
baked artifact, re-bake and redeploy it to update its bundled Rig. Use rig-infra v1.21.0
for the observer and rebuild the fleet runtime and dependent message overlays to record
publication identities. [rig-infra v1.21.0 release notes](https://github.com/christomaszewski/rig-infra/releases/tag/v1.21.0)
